Digital Guest Book

Project Overview

The Digital Guest Book is an interactive web application designed to digitally record visitor information and messages. It features a user-friendly form for visitors to submit their name, email, and message, along with a guest entry table that displays submitted data in real time. Each entry is automatically recorded with a timestamp showing the date and time of submission.

Why I Built It

Traditional guest books that rely on physical records can be inefficient, difficult to search, and vulnerable to data loss or damage. This project was developed to digitize the guest registration process, making visitor records more organized, centralized, and accessible while providing a more modern user experience.

Tech Stack & Tools

HTML / CSS PHP MySQL

Campus Clinic Information System

Project Overview

The Campus Clinic Information System is a web-based application designed to support the management of healthcare services within a university environment. The system provides comprehensive database management functionality, including patient registration, examination scheduling, and digital medical record management.

Why I Built It

Manual healthcare administration can slow down service processes and make it difficult to manage and track patient records. This project was developed to digitize clinic operations, making administrative workflows more efficient, structured, and easier to manage. It also served as a practical implementation of relational database design and CRUD operations for managing dynamic operational data.

Tech Stack & Tools

HTML / CSS PHP MySQL JavaScript

Material Stock Management System

Project Overview

A web-based inventory management information system designed to support daily operations at a building materials store. The application helps administrators manage material stock records and document incoming and outgoing inventory transactions, with all data stored in a centralized relational database.

Why I Built It

Manual inventory tracking can be prone to data discrepancies caused by human error and can make the stock-taking process less efficient. This system was developed to help digitize the administrator's workflow, making inventory records more organized, accurate, and easier to manage. This project also served as a practical implementation of database design and CRUD operations to address a real-world business need.

Tech Stack & Tools

HTML / CSS PHP MySQL

Digital Concert Ticketing Platform

Project Overview

An interactive web interface developed to simulate the process of purchasing concert tickets online. This project focused on front-end development, designing a user flow that guides users through selecting ticket categories and quantities, entering personal information, and viewing a checkout summary with dynamic interactions.

Why I Built It

Online concert ticket purchasing requires a fast, clear, and straightforward process so users can secure their desired tickets without unnecessary confusion. This project was designed to address the challenges of digital ticket booking by creating a smooth and intuitive purchasing interface. JavaScript was extensively implemented to handle interactive functionality, including buyer form validation and real-time ticket price calculations without requiring a page reload. This resulted in a more responsive and seamless user experience.
